#featureที่อยากได้
1. แสดงสีมงคลประจำวัน โดยแนะนำสไตล์การแต่งตัว เป็นตัวการ์ตูน น่ารักๆ
   [DONE] หน้าแรก / — สีประจำวัน + สีเสริมดวง + สีกาลกิณี ครบทั้ง 7 วัน
   [DONE] ตัวการ์ตูนวาดด้วย SVG ล้วน เปลี่ยนสีชุดตามสีมงคลของวันนั้นอัตโนมัติ
   [DONE] ชุดมี 3 ทรง (เดรส / เสื้อยืด / ฮู้ดดี้) สลับตามไอเดียแต่งตัวประจำวัน
   [DONE] ไอเดียแต่งตัว 3 แบบต่อวัน สุ่มด้วย seed จากวันที่ = ทั้งวันได้ชุดเดิม พอข้ามวันถึงเปลี่ยน
   [DONE] ของนำโชค / ทิศมงคล / เลขนำโชค ประจำวัน

2. เลือกดูดวงรายวัน รายสัปดาห์ รายเดือน
   [DONE] หน้า /horoscope — 12 ราศี x 3 ช่วงเวลา
   [DONE] แยกหมวด ความรัก / การงาน / การเงิน / สุขภาพ พร้อมคะแนนดาว
   [DONE] เลขนำโชค สีนำโชค คำแนะนำประจำช่วง
   [DONE] จำราศีที่เลือกไว้ใน localStorage ไม่ต้องเลือกใหม่ทุกครั้ง
   [DONE] คำทำนายคงที่ตลอดช่วง (เปิดกี่ครั้งก็ได้ผลเดิม) แล้วเปลี่ยนเมื่อขึ้นวัน/สัปดาห์/เดือนใหม่

3. สามารถเสี่ยงเซียมซีวัดดัง 4 ภาค และมีฟังก์ชัน เขย่าๆๆ ก่อนจะเปิดคำทำนาย
   [DONE] หน้า /siamsi — วัดโพธิ์ (กลาง) / ดอยสุเทพ (เหนือ) / พระธาตุพนม (อีสาน) / วัดพระมหาธาตุ (ใต้)
   [DONE] เขย่าโดยกดค้างที่กระบอก มีหลอดพลังและแอนิเมชันสั่น ปล่อยมือพลังจะลดลง
   [DONE] รองรับการสะบัดมือถือจริงผ่าน DeviceMotion (iOS มีปุ่มขออนุญาตให้)
   [DONE] วัดละ 8 ใบ มีคำกลอน 4 บรรทัด ระดับคำทำนาย และแยก 4 หมวด

4. สามารถดูไพ่ทาโร่ได้
   [DONE] หน้า /tarot — ไพ่ชุดหลัก Major Arcana 22 ใบ
   [DONE] เปิดได้ 2 แบบ: 1 ใบ (คำตอบ) และ 3 ใบ (อดีต-ปัจจุบัน-อนาคต)
   [DONE] มีไพ่กลับหัว คำทำนายคนละความหมายกับไพ่ตั้งตรง
   [DONE] แตะที่ไพ่เพื่อพลิก มีแอนิเมชันพลิก 3 มิติ

#ระบบ login (เปลี่ยนมาใช้ Supabase Auth แล้ว)
- ใช้ Supabase เป็นฐานข้อมูล เชื่อมด้วย Anon key + Project URL
  [DONE] สมัครสมาชิก / เข้าสู่ระบบ ด้วยอีเมล + รหัสผ่าน ผ่าน Supabase Auth
  [DONE] หน้า /login สลับแท็บระหว่างเข้าสู่ระบบกับสมัครสมาชิกได้
  [DONE] ยืนยันอีเมลผ่านลิงก์ รับกลับที่ /auth/callback แล้วแลก code เป็น session
  [DONE] หน้า /auth/auth-error สำหรับลิงก์ยืนยันหมดอายุหรือไม่สมบูรณ์
  [DONE] middleware ต่ออายุ session cookie ทุก request + กันหน้าที่ต้องล็อกอิน
  [DONE] ตรวจซ้ำในทุกหน้าด้วย getCurrentUser() ไม่พึ่ง middleware อย่างเดียว
  [DONE] ใช้ getUser() ไม่ใช่ getSession() เพราะ getUser() ยืนยัน token กับ Supabase จริง
  [DONE] ห่อ getCurrentUser ด้วย cache() ของ React กันยิง Supabase ซ้ำใน request เดียว
  [DONE] แปลข้อความ error ของ Supabase เป็นภาษาไทย
  [DONE] แสดงอีเมลผู้ใช้บนหัวเว็บ + ปุ่มออกจากระบบ
  [DONE] กัน open redirect ทั้งที่ Server Action และที่ /auth/callback
  ถอดของเดิมออกแล้ว: รหัส fixed, jose, APP_PASSWORD, SESSION_SECRET, rate limit ใน memory

  ต้องตั้งค่าฝั่ง Supabase Dashboard ด้วย:
  - Authentication > Providers > Email เปิดไว้
  - Authentication > URL Configuration ใส่ Site URL และ Redirect URL
    ให้ครอบคลุม <โดเมนจริง>/auth/callback และ http://localhost:3000/auth/callback
