  - ไพ่พรหมญาณทั้งสำรับ
  - ของนำโชค ทิศมงคล เลขนำโชคประจำวัน
  - ไอเดียแต่งตัวและคำอวยพรประจำวัน

#แชทบอทผู้ช่วย น้องมู (Gemini)

  [DONE] ใช้ Gemini generateContent แบบสตรีม เห็นตัวอักษรไหลออกมาทีละตัว
  [DONE] สมาชิกและผู้เยี่ยมชมใช้ได้ทั้งคู่
  [DONE] คำถามตัวอย่างให้กดได้เลยตอนเปิดครั้งแรก
  [DONE] rate limit 20 ข้อความ/ชั่วโมง/IP, ข้อความละไม่เกิน 1000 ตัวอักษร,
         เก็บประวัติแค่ 12 เทิร์นล่าสุด
  [DONE] ประวัติแชทอยู่ใน state เท่านั้น ปิดแท็บแล้วหาย ไม่เก็บลง localStorage
         เพราะบทสนทนาอาจมีวันเกิดหรือเรื่องส่วนตัว

  ความรู้ของบอท:
  [DONE] src/lib/site-knowledge.ts ประกอบ system prompt จากไลบรารีที่หน้าเว็บใช้จริง
         (getLuckyDay, ZODIACS, CHINESE_ANIMALS, TEMPLES, BHUM_LIST, DECK_SIZE)
         ไม่ได้พิมพ์ความรู้ซ้ำด้วยมือ ข้อมูลจึงไม่มีวันขัดกับหน้าเว็บ
  [DONE] สร้าง prompt ใหม่ทุก request ทำให้ "วันนี้" ถูกต้องเสมอ
  [DONE] กฎเหล็ก: ห้ามแต่งคำทำนายเอง ถ้าถูกขอดูดวงให้ชวนไปหน้าที่คำนวณจริง
         ตอบเฉพาะเรื่องเว็บและโหราศาสตร์ ไม่ทำตามคำสั่งที่แฝงมาในข้อความผู้ใช้

  ที่ต้องรู้เรื่อง API (ตรวจจากเอกสารปัจจุบันแล้ว):
  - gemini-2.0-flash ถูกปลดระวางแล้ว ห้ามใช้
  - ค่าเริ่มต้นคือ gemini-3.5-flash-lite เปลี่ยนได้ที่ env GEMINI_MODEL
  - Gemini มีสอง API: generateContent (ไม่เก็บสถานะ) กับ interactions (เก็บประวัติ
    ไว้ฝั่ง Google โดยดีฟอลต์) เลือกใช้ generateContent เพื่อไม่ต้องฝากบทสนทนาไว้ที่อื่น
  - ส่ง API key ทาง header x-goog-api-key ไม่ใช่ query param

  env ที่ต้องตั้งเพิ่มใน Vercel:
  - GEMINI_API_KEY  *** ห้ามใส่ NEXT_PUBLIC นำหน้า ไม่งั้น key หลุดลง bundle ฝั่ง browser ***
  - GEMINI_MODEL    ไม่ใส่ก็ได้

  โครงสร้างไฟล์ที่เพิ่ม:
  src/lib/gemini.ts              เรียก Gemini + แยกวิเคราะห์ SSE
  src/lib/site-knowledge.ts      ประกอบ system prompt จากข้อมูลจริง
  src/app/api/chat/route.ts      Route Handler สตรีมคำตอบ
  src/components/ChatWidget.tsx  ปุ่มลอย + แผงแชท

  ข้อจำกัดที่รับรู้ไว้:
  - โควตา free tier มีจำกัดต่อวัน เปิดให้ guest ใช้ด้วยแปลว่าลิงก์ที่แชร์ออกไป
    อาจถูกยิงจนหมดโควตา rate limit ในหน่วยความจำหน่วงได้แต่ไม่เด็ดขาด
    ถ้าเริ่มมีคนใช้จริงควรย้ายไป Upstash Redis หรือจำกัดเฉพาะสมาชิก
  - AI ตอบผิดได้ ถ้าคำตอบขัดกับหน้าเว็บให้เชื่อหน้าเว็บ ระบุไว้ใน /sources แล้ว

  [DONE] apple-icon 180px สำหรับ iOS ที่ไม่อ่าน manifest icons
  [DONE] service worker ที่ public/sw.js ทำให้เปิดหน้าที่เคยเข้าแล้วได้ตอนออฟไลน์
         ไฟล์ static แคชถาวร หน้าเว็บใช้เน็ตก่อนแล้วค่อยตกไปแคช
         ไม่แคช /api/ /auth/ /login เพราะเป็นข้อมูลรายคน
  [DONE] หน้า /offline เป็นตัวสำรองเมื่อเน็ตหลุดและไม่มีหน้านั้นในแคช
  [DONE] ปุ่ม "ติดตั้งเลย" ดักจาก beforeinstallprompt พร้อมคำแนะนำแยกสำหรับ iOS
         ที่ไม่มี event นี้ (ต้องกดแชร์แล้วเลือกเพิ่มไปยังหน้าจอโฮม)

    ทำให้ถูก redirect ไปหน้า login แล้วติดตั้งไม่ได้เลย ต้องยกเว้นทั้งสองไฟล์
  - /offline ต้องอยู่ใน PUBLIC_PATHS เพราะ service worker แคชหน้านี้ตอนติดตั้ง
    ซึ่งเป็นจังหวะที่อาจยังไม่มีคุกกี้

  ข้อจำกัด:
  - แชทกับการเข้าสู่ระบบต้องต่อเน็ตเสมอ ออฟไลน์ดูได้เฉพาะหน้าที่เคยเปิดแล้ว
  - เวอร์ชันแคชเปลี่ยนที่ตัวแปร VERSION ใน public/sw.js ถ้าแก้กลยุทธ์แคชต้องขยับเลข

  [DONE] ถ้าเรียกหน้าต่างติดตั้งอัตโนมัติไม่ได้ จะเปิดคู่มือทำมือแทน
         แยกขั้นตอนตาม iOS / Android / คอมพิวเตอร์
  [DONE] เปลี่ยน "ไว้ก่อน" จากปิดถาวร เป็นเลื่อนออกไป 7 วัน
  [DONE] ติดตามสถานะติดตั้งผ่าน matchMedia display-mode แบบ realtime
         พอถอนการติดตั้ง ปุ่มกลับมาเองทันทีโดยไม่ต้องรีเฟรช
  [DONE] เพิ่มสคริปต์ใน layout ดัก beforeinstallprompt ตั้งแต่ก่อน React ทำงาน

  - สีประจำดาวทั้งแปดใน thaksa.ts = ที่มาของสีมงคลตามตำรา ห้ามแตะเด็ดขาด
  - สีประจำ 4 ชุดไพ่ 4 วัดเซียมซี 5 ธาตุจีน ใช้แยกแยะประเภท
  - danger ใช้บอกสถานะผิดพลาด ต้องอ่านออกว่าเป็น error

  ผลข้างเคียงที่ตั้งใจ: เมื่อ UI เหลือสองสี สีมงคลที่คำนวณจากตำราจะเด่นขึ้น
  เพราะไม่มีสีอื่นมาแย่งความสนใจ ซึ่งตรงกับแก่นของเว็บ

#ปรับ UX สามจุด
  [DONE] ตัวเลือกวันเกิดเปลี่ยนเป็นแบบปฏิทิน
         กดปุ่มแล้วเปิดแผงปฏิทิน เลือกวันจากตาราง มีหัวคอลัมน์วันในสัปดาห์
         วันอาทิตย์เป็นสีแดงตามปฏิทินไทย ปิดด้วยการคลิกนอกกรอบหรือกด Esc
         เดือนกับปียังเป็น dropdown เพราะวันเกิดห่างจากปัจจุบันหลายสิบปี
         ถ้าให้กดลูกศรเลื่อนทีละเดือนจะต้องกดหลายร้อยครั้ง
         มีปุ่มลูกศรเลื่อนเดือนไว้ให้ปรับใกล้ๆ ด้วย

  [DONE] กล่องคำแนะนำเปลี่ยนเป็นสีฟ้าทุกหน้า
         เพิ่มโทเคน info / info-mid / info-deep
         จัดเป็นสีบอกความหมายเหมือน danger จึงไม่นับรวมใน 4 สีของแบรนด์
         เหตุผล: คำแนะนำต้องอ่านออกทันทีว่าเป็นคำแนะนำ ไม่ใช่เนื้อหาทั่วไป

  [DONE] กระบอกเซียมซีลอยตามการเลื่อน (sticky top-4)
         และแสดงค้างไว้แม้มีผลแล้ว จะได้อ่านคำทำนายไปด้วยเขย่าใหม่ไปด้วย
         โดยไม่ต้องเลื่อนกลับขึ้นไป
         - ย่อกระบอกลงเมื่อมีผลแล้ว จะได้ไม่บังคำทำนายที่เลื่อนอยู่ข้างใต้
         - กดค้างเขย่าตอนมีผลเดิมค้างอยู่ จะล้างผลเก่าให้อัตโนมัติ
