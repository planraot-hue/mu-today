# ตัวอย่างไอคอนแอป

ไฟล์ในโฟลเดอร์นี้ใช้ดูเปรียบเทียบไอคอนก่อนตัดสินใจ
ไม่ได้ถูกใช้งานตอนรันเว็บ — ไอคอนจริงสร้างจาก
[`src/lib/app-icon.tsx`](../../src/lib/app-icon.tsx) ตอน request

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `icon-comparison.png` | แผ่นเปรียบเทียบทุกแบบ พร้อมแถวขนาดใช้งานจริงบนพื้นสว่างและพื้นมืด |
| `icon-crystal-256.png` | **ลูกแก้วมีจันทร์เสี้ยว — แบบที่ใช้อยู่ตอนนี้** |
| `icon-ball-256.png` | ลูกแก้วเรียบๆ ไล่สีชมพู-ม่วง |
| `icon-moon-256.png` | จันทร์เสี้ยวบนพื้นม่วงเข้ม |
| `icon-star-256.png` | ประกายดาวบนพื้นทอง-ชมพู |
| `preview.html` | หน้าเปรียบเทียบสามแบบแรก เปิดในเบราว์เซอร์ได้เลยไม่ต้องต่อเน็ต |
| `render-icons.ps1` | สคริปต์ที่ใช้เรนเดอร์ PNG พวกนี้ |

## ลายลูกแก้วมี 2 ระดับรายละเอียด

ลายนี้มีฐาน ดาว และประกายรอบตัว ซึ่งกลายเป็นจุดมั่วเมื่อย่อลงมาที่ 16px
จึงแยกเป็นสองเวอร์ชัน

| ขนาด | ใช้เวอร์ชัน | มีอะไรบ้าง |
|---|---|---|
| favicon 32px ลงมา | ย่อ | ลูกแก้ว + จันทร์เสี้ยว (ลูกแก้วใหญ่เต็มกรอบกว่า) |
| apple-icon 180, manifest 192/512 | เต็ม | ครบทั้งฐาน ดาว ประกาย และขีดสีทอง |

ดูเทียบกันได้ที่แถวล่างสุดของ `icon-comparison.png`

## ⚠️ favicon เป็นไฟล์นิ่ง ไม่ได้ตามค่า ICON_STYLE

`src/app/icon.png` เป็นสำเนาของ `icon-crystal-256.png` ในโฟลเดอร์นี้
ถ้าเปลี่ยน `ICON_STYLE` เป็นลายอื่น **favicon จะไม่เปลี่ยนตาม** ต้องคัดลอกไฟล์ทับเอง

```powershell
copy docs\icon-preview\icon-<ลาย>-256.png src\app\icon.png
```

ส่วน apple-icon กับไอคอน 192/512 สร้างจาก `app-icon.tsx` จึงเปลี่ยนตามอัตโนมัติ

## เปลี่ยนไอคอนที่ใช้จริง

แก้บรรทัดเดียวใน [`src/lib/app-icon.tsx`](../../src/lib/app-icon.tsx)

```ts
export const ICON_STYLE: IconStyle = "crystal";  // "crystal" | "ball" | "moon" | "star"
```

favicon, apple-icon และไอคอน 192/512 จะเปลี่ยนตามพร้อมกันทั้งหมด

## เรนเดอร์ PNG ใหม่หลังแก้ลาย

```powershell
powershell -File docs/icon-preview/render-icons.ps1
```

สคริปต์วาดด้วย GDI+ ของ .NET จึงรันได้บน Windows โดยไม่ต้องมี Node.js

> ⚠️ สคริปต์นี้ทำสำเนาค่าสีและสัดส่วนไว้เอง ถ้าแก้ลายใน `app-icon.tsx`
> ต้องแก้ในสคริปต์ให้ตรงกันด้วย ไม่งั้นตัวอย่างจะไม่ตรงกับของจริง
