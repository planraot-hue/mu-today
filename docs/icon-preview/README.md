# ตัวอย่างไอคอนแอป

ไฟล์ในโฟลเดอร์นี้ใช้ดูเปรียบเทียบไอคอน 3 แบบก่อนตัดสินใจ
ไม่ได้ถูกใช้งานตอนรันเว็บ — ไอคอนจริงสร้างจาก
[`src/lib/app-icon.tsx`](../../src/lib/app-icon.tsx) ตอน request

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `icon-comparison.png` | แผ่นเปรียบเทียบทั้ง 3 แบบ แถวล่างสุดคือขนาดใช้งานจริงบนพื้นมืด |
| `icon-ball-256.png` | แบบ 01 ลูกแก้วพยากรณ์ |
| `icon-moon-256.png` | แบบ 02 จันทร์เสี้ยว (ที่ใช้อยู่ตอนนี้) |
| `icon-star-256.png` | แบบ 03 ประกายดาว |
| `preview.html` | หน้าเปรียบเทียบแบบเปิดในเบราว์เซอร์ ดับเบิลคลิกเปิดได้เลย ไม่ต้องต่อเน็ต |
| `render-icons.ps1` | สคริปต์ที่ใช้เรนเดอร์ PNG พวกนี้ |

## เปลี่ยนไอคอนที่ใช้จริง

แก้บรรทัดเดียวใน [`src/lib/app-icon.tsx`](../../src/lib/app-icon.tsx)

```ts
export const ICON_STYLE: IconStyle = "moon";  // "ball" | "moon" | "star"
```

favicon, apple-icon และไอคอน 192/512 จะเปลี่ยนตามพร้อมกันทั้งหมด

## เรนเดอร์ PNG ใหม่หลังแก้ลาย

```powershell
powershell -File docs/icon-preview/render-icons.ps1
```

สคริปต์วาดด้วย GDI+ ของ .NET จึงรันได้บน Windows โดยไม่ต้องมี Node.js

> ⚠️ สคริปต์นี้ทำสำเนาค่าสีและสัดส่วนไว้เอง ถ้าแก้ลายใน `app-icon.tsx`
> ต้องแก้ในสคริปต์ให้ตรงกันด้วย ไม่งั้นตัวอย่างจะไม่ตรงกับของจริง
