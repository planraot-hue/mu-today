# ไอคอนและรูปพรีวิวของเว็บ

โฟลเดอร์นี้เก็บทั้งไฟล์ตัวอย่างสำหรับเปรียบเทียบ และสคริปต์ที่สร้างไฟล์จริงที่เว็บใช้งาน

## ไอคอนทั้งหมดเป็นไฟล์นิ่ง สร้างจากสคริปต์

เดิมสร้างตอน request ด้วย `ImageResponse` ของ Next.js แต่เปลี่ยนมาเป็นไฟล์นิ่ง
เพราะ satori ที่อยู่เบื้องหลังรองรับ CSS ไม่ครบ และตรวจผลก่อน deploy ไม่ได้เลย
ลายลูกแก้วมีวงกลมทับกันกับวงรีหมุน ถ้า satori วาดไม่ตรงจะพังแบบเงียบๆ
ไฟล์นิ่งเปิดดูด้วยตาได้ก่อนส่งขึ้นจริง

| ไฟล์ปลายทาง | ขนาด | ใช้ทำอะไร |
|---|---|---|
| `src/app/icon.png` | 256 | favicon |
| `src/app/apple-icon.png` | 180 | iOS หน้าจอโฮม |
| `public/icon-192.png` | 192 | manifest |
| `public/icon-512.png` | 512 | manifest + maskable |
| `public/og.png` | 1200×630 | รูปพรีวิวตอนแชร์ลิงก์ |

## สร้างไฟล์ใหม่หลังแก้ลาย

```powershell
powershell -File docs/icon-preview/render-icons.ps1   # ไอคอนทุกขนาด
powershell -File docs/icon-preview/render-og.ps1      # รูปพรีวิวแชร์ลิงก์
```

สคริปต์วาดด้วย GDI+ ของ .NET จึงรันได้บน Windows โดยไม่ต้องมี Node.js
แก้ลายได้ที่ฟังก์ชัน `Draw-Crystal` ใน `render-icons.ps1`

> ⚠️ **ไฟล์ .ps1 ต้องบันทึกเป็น UTF-8 with BOM เท่านั้น**
> PowerShell 5.1 อ่านไฟล์ที่ไม่มี BOM เป็น ANSI ทำให้ข้อความไทยเพี้ยนทั้งหมด
> เคยเจอมาแล้วตอนทำ `og.png` ครั้งแรก ตัวหนังสือกลายเป็นอักขระมั่วทั้งรูป

## ไฟล์ตัวอย่างสำหรับเปรียบเทียบ

ไม่ได้ถูกใช้งานตอนรันเว็บ มีไว้ดูอย่างเดียว

| ไฟล์ | คืออะไร |
|---|---|
| `icon-comparison.png` | แผ่นเปรียบเทียบทุกลาย พร้อมแถวขนาดใช้งานจริงบนพื้นสว่างและพื้นมืด |
| `icon-crystal-256.png` | **ลูกแก้วมีจันทร์เสี้ยว — ลายที่ใช้อยู่จริง** |
| `icon-ball-256.png` | ลูกแก้วเรียบๆ ไล่สีชมพู-ม่วง |
| `icon-moon-256.png` | จันทร์เสี้ยวบนพื้นม่วงเข้ม |
| `icon-star-256.png` | ประกายดาวบนพื้นทอง-ชมพู |
| `preview.html` | หน้าเปรียบเทียบสามลายแรก ดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย |

## ลายลูกแก้วมี 2 ระดับรายละเอียด

ฐาน ดาว และประกายรอบตัวกลายเป็นจุดมั่วเมื่อย่อลงมาที่ 16px
สคริปต์จึงรองรับพารามิเตอร์ `-detail` ไว้

ตอนนี้ไฟล์จริงทุกขนาดใช้เวอร์ชันเต็ม เพราะเบราว์เซอร์ย่อ 256px ลงเองได้ดีอยู่แล้ว
ถ้าอยากให้ favicon ทนการย่อมากขึ้น ให้แก้ `render-icons.ps1` ตรงรายการ `$targets`
เปลี่ยน `src\app\icon.png` เป็น `-detail $false`
